# 知山 KnowShan — 刘看山 AI 数字伙伴 MVP

> 知乎黑客松 S3 · 湾区共创季｜赛道 02：AI × 陪伴与交互（数字伙伴 / 软硬一体）

## 一键运行

```bash
cd knowshan-mvp
npm install
npm run dev
```

浏览器打开 `http://localhost:3000` 即可体验软硬双端联动原型。

## 可选：接入知乎看山工作台 / OpenAI 兼容大模型

默认内置零延迟启发式陪伴、语义问题匹配与 AI 隐私脱敏引擎（无 Key 亦可完整演示闭环）。如需接入真实大模型 API，可在根目录新建 `.env.local`：

```env
LLM_API_KEY=你的密钥
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

## 核心已实现模块

1. **实体包挂 3D 交互原型（Three.js + 动态曲面 OLED 眼屏）**：
   - 拖拽 360° 观察北极狐刘看山毛绒包挂、挂绳金属扣与实时同步穿戴配饰；
   - **捏住鼻子语音倾诉**（支持浏览器 Web Speech 语音识别 + 声波眼屏动画 + 无麦克风快捷剧本芯片）；
   - **摸头顺毛、捏脸触发「奸诈的笑 ¬‿¬」、模拟熬夜长出黑眼圈、拍拍哄睡熄屏**；
   - 内置硬件工业设计参数说明抽屉（ESP32-S3 + 1.28" 柔性 OLED + 鼻尖微动传感器）。
2. **知乎内嵌网页虚拟宠物空间**：
   - **冒泡提问（问题发现 + 知乎直答社区洞察）**：根据语音倾诉与用户画像动态推荐高契合知乎问题并进行苏格拉底式低压力探讨；
   - **堆雪人成稿 + AI 隐私脱敏引擎**：融合语音碎片与探讨内容自动成稿，并用 **AI 隐私脱敏保护** 合规替代知乎已下线的“匿名回答”；
   - **正反馈与软硬一体装扮养成**：发布后即时模拟知友赞同与暖心评论，获取 `+120 EXP` 解锁眼镜、银鳕鱼、礼帽并实时同步到 3D 包挂；
   - **看山囤货 & 性格镜像引擎（MBTI + OAuth 阅读画像）**。
